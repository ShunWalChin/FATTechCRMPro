      Três alertas que decidiram o desenho

      bloqueado

      API grátis da NVIDIA

      Os termos da API trial proíbem produção e dado pessoal, e a NVIDIA usa o conteúdo para treino. Fica só nos evals sintéticos; o bootstrap aborta se achar a chave em produção.

      a medir

      Português do Nano

      O Nemotron 3 Nano não lista português entre os idiomas. T1 começa em tarefa interna; texto para cliente só depois do eval.

      descartado

      Nano 30B no desktop

      24 GB não cabem em 8 GB de VRAM. O offload travaria a máquina. O 4B cabe com folga.

      docs/08-roadmap.md

      Ondas com critério de saída

      Uma onda só fecha quando o critério é verificado. A seguinte não começa antes.

      0

      Terreno · ≈ 1 semana

      Auditoria do H1, limpeza verificada, Tailscale com ACL, Doppler.

      Critério memória do H1 ≤ 75%, portas 18789/8443 livres, testes da ACL passando.

      1

      Cérebro em modo sombra · ≈ 1 semana

      Confirmar modelos, rodar o eval, provisionar agentes pausados, subir o gateway, parear o WhatsApp do Marvin.

      Critério 5 dias úteis de briefings 08/12/18h com custo real por ciclo em agent_runs.

      2

      Squad em sugestão · 2–3 semanas

      Ativar SDR → Cobrança → Tráfego → Conteúdo → Sentinela; n8n como ferramentas MCP; alerta externo do H1.

      Critério ≥ 70% de rascunhos aplicados, zero lead quente sem retorno no dia, custo ≤ US$ 25/mês.

      3

      Autonomia interna · 3–4 semanas (Ruflo)

      E3, reciclagem de corridas, aidefence, testes de campanhas.

      Critério agentes movem card e agendam tarefa sem pessoa; recusa por teto aparece como refused.

      4

      Canal oficial e execução externa

      WhatsApp Cloud API via BSP, E5, agenda.

      Critério mensagem aprovada sai pelo outbox com compliance no instante do envio; opt-out recusado e auditado.

      5

      Produto

      “Funcionário digital FAT Tech” por cliente: mesmo artefato, topologia por variável de ambiente.

      Critério primeiro cliente com SDR IA e custo de modelo abaixo de 10% do ticket.
