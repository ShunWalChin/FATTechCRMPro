# ADR-004 · Modelos Nemotron-first por nível de privacidade

- **Status:** aceito · 2026-09-27
- **Decisores:** Walfredo Neto (CEO) · proposto pelo Palantyr v5

## Contexto
Pedido do Wal: rodar em NVIDIA Nemotron. Termos da API trial da NVIDIA proíbem produção e dado pessoal e usam o conteúdo para treino. Nemotron 3 Nano não lista português. RTX 4060 tem 8 GB.

## Decisão
T0 regra no CRM; T1 Nemotron 3 Nano 4B no desktop via node_inference; T2 Nemotron 3 Super (Marvin) e 3.5 Lightning (squad) pagos via OpenRouter com data_collection deny + zdr; T3 Claude Sonnet como fallback. API trial NVIDIA só em evals sintéticos; bootstrap aborta se encontrar a chave em produção. Nenhum modelo assume papel sem evals/ptbr aprovado.

## Consequências
Custo estimado de US$ 10–25/mês contra US$ 150–300 com tudo em Sonnet. Risco de PT-BR tratado por gate, não por fé.

## Alternativa descartada
Nemotron via API grátis da NVIDIA: viola os termos e a LGPD. Nano 30B local: não cabe na VRAM.
