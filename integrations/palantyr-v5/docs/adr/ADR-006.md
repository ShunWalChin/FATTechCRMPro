# ADR-006 · Um gateway, seis agentes, uma identidade por agente

- **Status:** aceito · 2026-09-27
- **Decisores:** Walfredo Neto (CEO) · proposto pelo Palantyr v5

## Contexto
v2 usava dois WSL e um blackboard em arquivos porque o desktop desligava. Na Oracle, um gateway OpenClaw hospeda vários agentes isolados com delegação nativa.

## Decisão
Gateway único no H1 com marvin + 5 agentes. Cada agente: workspace, chave do CRM e ponte MCP próprias; tools.deny das pontes alheias; só o Marvin delega (subagents.allowAgents) e só ele tem canal.

## Consequências
Blackboard do v2 aposentado. Isolamento por configuração verificada (openclaw doctor / mcp probe).

## Alternativa descartada
Um gateway por agente: 6× memória e manutenção sem ganho de isolamento relevante no mesmo host.
