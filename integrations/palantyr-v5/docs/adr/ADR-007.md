# ADR-007 · Nenhum agente tem shell; sem docker.sock

- **Status:** aceito · 2026-09-27
- **Decisores:** Walfredo Neto (CEO) · proposto pelo Palantyr v5

## Contexto
O blueprint do CRM previa docker.sock no OpenClaw para sandbox — equivalente a root no host com 71 contêineres. openclaw doctor alerta exec sem sandbox.

## Decisão
exec, process, apply_patch e browser negados para todos. Saúde da infra por MCP palantyr-probe: lista fechada de alvos, só GET, sem redirecionamento. Correção é da engenharia Ruflo.

## Consequências
Sem sandbox, sem socket, sem leitura de ambiente pelo agente. Sentinela observa mas não conserta.

## Alternativa descartada
Sandbox Docker com socket: poder máximo com o maior risco do host.
