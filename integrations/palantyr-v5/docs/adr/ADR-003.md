# ADR-003 · n8n é braço externo, fora do caminho agente↔CRM

- **Status:** aceito · 2026-09-27
- **Decisores:** Walfredo Neto (CEO) · proposto pelo Palantyr v5

## Contexto
O n8n já orquestra Meta, Google e Evolution no H2. O CRM já assina, deduplica e tem carta morta.

## Decisão
n8n expõe ações externas como ferramentas MCP (MCP Server Trigger) na tailnet; credenciais de terceiros ficam no n8n. n8n acorda agentes por hook sem carregar dado. Entre OpenClaw e CRM não há n8n.

## Consequências
Um caminho de dado (o CRM). Ferramentas externas com esquema fixo e prefixo acao_* para as de escrita, negáveis em bloco.

## Alternativa descartada
n8n como barramento obrigatório: acrescenta salto que falha sem acrescentar garantia.
