# ADR-005 · Ruflo é o squad de engenharia, não o runtime

- **Status:** aceito · 2026-09-27
- **Decisores:** Walfredo Neto (CEO) · proposto pelo Palantyr v5

## Contexto
Ruflo é um meta-harness para Claude Code/Codex: coordena escrita, teste e revisão de código. O CRM já usa Ruflo pinado como ferramenta de engenharia.

## Decisão
OpenClaw opera o negócio; Ruflo constrói e mantém o sistema, por PR, com gates (security scan, mcp-scan, adr-review, testes). Contato entre os dois: tarefa eng:ruflo no CRM.

## Consequências
Evita o segundo motor (dívida fattech:walchat:two-engines-debt). Deploy continua humano.

## Alternativa descartada
Ruflo operando leads: sem canal, sem portão de negócio; duplicaria o OpenClaw.
