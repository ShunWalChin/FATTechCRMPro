# ADR-008 · Rede: loopback + tailnet; nada novo na internet

- **Status:** aceito · 2026-09-27
- **Decisores:** Walfredo Neto (CEO) · proposto pelo Palantyr v5

## Contexto
No H1 o nginx de sistema é dono de 80/443; no H2, o NPM. O painel do OpenClaw não pode ficar aberto.

## Decisão
Gateway publicado em 127.0.0.1:18789; tailscale serve --https=8443 no host; ACL com negar por padrão e tests (Wal, desktop GPU, borda↔núcleo). Sem SSH pela tailnet.

## Consequências
Hooks do n8n e nó GPU só pela tailnet. Tailscale vira dependência (mitigada pelo cron de segurança do SDR).

## Alternativa descartada
Subdomínio público com Basic Auth ou Cloudflare Access: aumenta superfície sem necessidade.
