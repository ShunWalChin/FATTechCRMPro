# Depuração geral — 27/09/2026

Escopo: API, interface, ponte Palantyr MCP, scripts de apoio e pipeline de integração contínua.
Este relatório registra verificações reproduzíveis; não afirma ausência de defeitos em caminhos
que os testes não exercem nem equivalência entre o ambiente local e produção.

## Correções desta rodada

- Removidos 20 apontamentos de Ruff em imports, string e nomes de variáveis; os imports tardios
  necessários à configuração isolada do navegador foram marcados explicitamente.
- Acrescentados testes de reindexação e isolamento de documentos, CRUD versionado de campanhas e
  autorização do contrato do Core-Engine. O inventário agora encontra 131 rotas, zero sem teste e
  zero órfãs conforme seu método de análise textual.
- A CI passou a exigir Ruff e os testes e a auditoria de dependências da ponte Palantyr MCP.
- Documentados os contratos das rotas de indexação e Core-Engine em `apps/api/API.md`.

## Verificações

| Camada | Resultado |
| --- | --- |
| API | 365 testes passaram, 12 foram ignorados; duas advertências de depreciação em dependências de teste |
| Navegador | 48 cenários Playwright passaram localmente |
| Frontend | TypeScript e build de produção passaram |
| Palantyr MCP | 20 testes passaram |
| Python | Ruff e `compileall` passaram |
| Dependências | `npm audit --omit=dev --audit-level=high` encontrou zero vulnerabilidades no app e na ponte MCP |
| Segredos | `scripts/check_secrets.py` não encontrou padrões de credenciais nos candidatos do repositório |
| Inventário | 131 rotas; nenhuma classificada como sem teste ou órfã |

No Windows desta estação, o Playwright concluiu os 48 cenários, mas aguardou o término dos dois
servidores locais iniciados para o teste. Encerrar esses processos de teste fez o runner sair com
código zero. A CI usa Linux e continua executando a mesma suíte como gate. O Graphify atualizou o
grafo, mas ainda emite avisos de parser para `crm-ui.tsx` e de schema para nós curados; o build e
os testes não apontaram erro nesse componente.

## Limite operacional

Este diagnóstico cobre o código local. Publicação na Oracle e conferência da versão em produção
dependem de acesso SSH válido para `opc` no servidor; o acesso disponível nesta sessão ainda não
autenticou esse usuário. Não tratar este relatório como prova de deploy.
