# Versão 0.7.0 — copiloto SYNAPSE e portão Palantyr

Estado: código local validado; ainda não publicado. A produção Oracle respondia `0.5.1` em 27/09/2026 antes desta entrega.

## Comportamento entregue no código

- O SYNAPSE mantém sua resposta extrativa e, quando o operador configura um endpoint OpenAI-compatible e a organização habilita `ai_enabled`, oferece uma segunda versão gerada como **rascunho para revisão humana**. O resultado cita até três fontes atuais, preserva o texto extrativo, registra modelo e uso, é idempotente e nunca vira mensagem enviada. A fonte e o opt-out são reavaliados depois da chamada ao modelo.
- Um endpoint remoto de IA exige `FATTECH_AI_REMOTE_ENABLED=true`, desligado por padrão. E-mail, telefone, CPF e CNPJ comuns são mascarados na pergunta e nos trechos antes da chamada. Isso é minimização, não detecção exaustiva de dados pessoais; políticas de subprocessador e transferência seguem pendentes antes de usar provedores externos com dados reais.
- O pacote Palantyr v5 está versionado em `integrations/palantyr-v5`. A ponte MCP compilou e passou 20 testes locais. O CRM agora vincula toda operação de corrida à identidade de agente emissora da chave; o MCP só consulta a própria fila.
- O compose do gateway OpenClaw fica separado do compose do CRM e está apenas preparado. Nenhum agente foi provisionado ou ativado. Nenhum canal externo ou provedor de modelo foi ligado por esta entrega.

## Limites de produção

- O site e a API em Oracle continuam na versão anterior até release verificável. O acesso SSH com a chave fornecida foi recusado pelo host para os usuários `opc` e `ubuntu`; credenciais de GitHub também não estavam válidas nesta máquina.
- Os scripts de auditoria, limpeza e bootstrap do pacote são material de operação, não etapas executadas automaticamente. A limpeza de serviços exige inventário vivo e verificação do backup antes de qualquer execução.
- A configuração OpenClaw do arquivo recebido foi revisada como proposta. A verificação `openclaw config validate` no host, conectividade da rede Docker, segredos, IDs dos modelos Nemotron e custos ainda dependem do H1.
- Envio WhatsApp/Instagram permanece condicionado a adaptadores oficiais, opt-out, janela e aprovação; a geração de texto não habilita envio.
